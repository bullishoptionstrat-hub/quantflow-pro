## Verdict in one paragraph

The deployed product is a **simulation rendered as a live trading terminal**. With the
default (no-API-key) configuration, every flow event, dark-pool print, GEX level, and
options chain a user sees is generated by `Math.random()` — on the backend *and again
independently on the frontend* — and none of it was labeled synthetic anywhere in the
API or UI. The ML service's advertised model trains on rng-generated fiction and reports
AUC 1.0000 (reproduced this session). No route requires authentication. Nothing is ever
persisted to Supabase despite a full schema with RLS policies. There is no timezone bug
of the kind previously reported — the reported EDT hardcode does not exist in this tree.

## The four known claims — verdicts

1. **ml-service/train.py train/eval leak** → **REFUTED as stated; the real defect is worse and is CONFIRMED as the alternative described.** Split hygiene is textbook-correct (`train_test_split`, stratified, no leakage between rows). The model is meaningless anyway because *both* splits are the same rng fiction: labels drawn first (`is_unusual = rng.random() < 0.25`, `train.py:40`), features then drawn from label-conditioned, largely non-overlapping distributions. Verified empirically: `size_norm` ranges are disjoint (unusual 5.41–8.52 vs normal 0.69–4.61), one feature is constant 0.2, AUC reproduces at exactly 1.0000. Finding #4.

2. **Hardcoded EDT offset (UTC−4)** → **NOT FOUND.** Searched the entire tree (backend, frontend, ml-service, modules, SQL, scripts, README, zips' file listings) for offset arithmetic (`-4`, `14400`, `getTimezoneOffset`, `EDT`, `EST` variants). All timezone conversion uses the IANA `America/New_York` zone, which is DST-correct. No fix fabricated. The nearest real (minor) issues are the FlashAlpha midnight mislabel and missing holiday calendar (Finding #22).

3. **backend/tsconfig include=["src/**/*"] leaves stray scripts/tests untypechecked** → **CONFIRMED as a config fact, but the stray-file list is EMPTY** — before this session `backend/` had no `.ts` file outside `src/`. Latent, not active. Closed anyway (Finding #17, Safe Fix 1).

4. **ingestion/index.ts simulates flow + dark pool with Math.random() and registers sources['simulation']='connected'** → **CONFIRMED, and the blast radius is larger than claimed.** Beyond `startSimulationFeed` (`:473-491`) and `sources['simulation']='connected'` (`:481`): seed data (50 events, `:575-631`), dark-pool generator (`:547-573`), synthetic GEX for *all* symbols (`:633-661`), mock chains with random greeks (`routes/chain.ts:80-126`), fabricated heat-score inputs on real feeds (#11), Finnhub path that *generates* option flow from equity ticks at random (`:454-456` — `Math.random() > 0.85 → generateFlowFromSpot(...,'finnhub')`, so even the "real" finnhub source emits invented option trades), plus the frontend's independent generator (#8). Everything flows into one store and one socket stream. Note the Finnhub case is the most insidious: synthetic events labeled with a *real* source name — this is why the emit-boundary guard added this session checks provenance, and why `generateFlowFromSpot` now tags `synthetic:true` unconditionally regardless of the source string it is passed.

## Safe fixes implemented this session (all reversible, tested)

1. **Typecheck coverage** — `backend/tsconfig.all.json` (src+test+scripts graph, `noEmit`), `backend/tsconfig.test.json` (compile-to-`.test-build` for `node --test`), `npm run typecheck` / `npm test` scripts. Root `package.json` `npm run verify` orchestrates: backend types → backend tests → backend build → flow-engine typecheck+tests → firecrawl typecheck → frontend env preflight → frontend typecheck → frontend build.
2. **Startup env guards** — `backend/src/config/env.ts` + `assertEnvOrExit()` in `server.ts`: production refuses to boot on missing/blank `SUPABASE_URL`/`SUPABASE_SERVICE_KEY`, partial secret groups (schwab/tastytrade/reddit/supabase) and invalid `DATA_MODE` are rejected; blank-string secrets are treated as absent; secret **values are never printed** (test-asserted). 13 tests in `backend/test/env.test.ts`.
3. **DATA_MODE=live|demo** — `backend/src/config/dataMode.ts`. Live mode: simulation feed refuses to start, synthetic GEX returns `[]`, mock chains/expirations return 502/503, dark-pool generator no-ops, and the single emit boundary (`addFlowEvent`) drops any synthetic event. Demo mode (default — honest default for a keyless build): every generator output passes through `markSynthetic()` ⇒ carries `synthetic: true`; an untagged event from a synthetic source is dropped at the boundary in *any* mode. `/api/health` now reports `dataMode`. 18 tests (`dataMode.test.ts` unit + `ingestionProvenance.test.ts` integration against the real ingestion module) prove: no synthetic event is emittable untagged.

Everything else above is documentation only, per scope.
